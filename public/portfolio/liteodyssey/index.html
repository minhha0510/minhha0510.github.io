Diagnostic policyⓘThe policy is a natural-language document that integrates expert diagnostic reasoning principles, specialized biomedical tools and the rules for using them, organized as an eight-phase workflow. How the policy learned

Policy Iteration with Human Feedback

  1. Run the current policy on the 50-case development set
  2. Locate recurrent failures by reasoning stage
  3. Gate revisions clinically
  4. Persist the improved policy

↺ next evaluation round

Model weights stay frozen. The written policy transfers across models.
The harness that automates this loop: PIHF-MCP

1,193 of the public cases, covering 679 diseases, were never used in policy development. Four reasoning models each improved over their matched baselines (baselines 18.7% to 26.5%). In the UDN cohort, blinded physician review corroborated the gain.

Matched baseline: the same model and clinical features without the policy or tools. Public-benchmark scores use a judge from a different model family than the one evaluated; exact-OMIM sensitivity analyses are in the preprint.
